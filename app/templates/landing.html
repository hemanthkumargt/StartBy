A task manager for people with deadlines

Know when to start, not just when it's due.

01

What it does

Every feature feeds the same start-by calculation, so the answer improves the more you use it.

  1. Start-by time

    Give a task an effort estimate. StartBy subtracts the time you'll need, with a margin, from the due date, and shows you the result on every card.

    due − estimate × pace × 1.15

  2. Risk radar

    Each task is colour-coded from calm to urgent, always with a text label as well, never colour alone. A "Do this now" card puts the single most urgent task first.

  3. Adaptive replanning

    Missed the start time, or moved the deadline? The plan recomputes on its own instead of quietly going stale.

  4. Your own pace

    A multiplier per tag is learned from actual versus estimated hours on finished tasks. If study work always takes 1.6 times your guess, the plan knows.

  5. Smart capture

    Paste a handout, drop in a PDF or type "lab report friday 6pm". Gemini pulls out tasks and dates; a local parser takes over if the API is slow, so capture never fails.

    Gemini → regex + dateparser fallback

  6. Voice assistant and notes

    Add tasks, ask what's next, or record a note without touching the keyboard.

  7. Start-now reminders

    An email when it's time to begin. Each is sent once, and retried if a send fails.

  8. Overload warning and report card

    See a crunch coming before it arrives, then review how accurate your estimates turned out to be.

02

How it works

  1. 1

    Capture

    Type it, say it, paste a syllabus or upload a PDF. Titles, due dates and estimates are filled in for you to confirm.

  2. 2

    Plan

    Each task gets a latest-start time and a risk label. The dashboard puts the most urgent one up front.

  3. 3

    Learn

    A reminder lands when it's time. Finish the task and StartBy learns from how long it really took.
